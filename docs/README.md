# Документация проекта

Документы для разработчиков и тех, кто разворачивает рекомендатель.

## Разделы

- [Архитектура и поток данных](architecture.md) — компоненты, хранение признаков и устройство рекомендаций.
- [Запуск и эксплуатация](operations.md) — локальный старт, конфигурация, база данных, API-доступ и мониторинг.
- [API](api.md) — основные группы REST-эндпоинтов и ссылка на OpenAPI-контракт.
- [Оценка качества и тюнинг](evaluation.md) — метрики, выбор целевой функции и процедура проверки.
- [Ручная оценка выдачи](manual-evaluation.md) — отмеченные пользователем рекомендации для сравнения версий.

Быстрый старт и подробные примеры использования остаются в [корневом README](../README.md).
Контракт API хранится в [openapi.json](openapi.json) и обновляется командой `make openapi`.
