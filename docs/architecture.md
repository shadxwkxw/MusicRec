# Архитектура

Проект — контентный рекомендатель музыки с REST API на FastAPI, batch CLI и опциональными задачами Airflow. Основной код разделён на `domain`, `application`, `infrastructure` и `interfaces` внутри `src/recommender`.

## Поток данных

```text
аудио → извлечение признаков → БД → нормализация и веса → FAISS-индекс
                                                     ↑              ↓
                                      лайки → co-like boost → выдача
```

В режиме `librosa` извлекаются 82 числовых признака. В режиме `embedding` текстово-аудио модель формирует векторные представления; для него нужны дополнительные зависимости (`make install-embeddings`) и предварительный batch-шаг `make batch-embed`. Режим выбирается через `FEATURE_SOURCE`.

Сырые признаки и сведения о треках хранятся в БД. Нормализованные артефакты и FAISS индекс сохраняются в `data/models/` и `data/index/`; при S3-хранилище индекс может зеркалироваться туда. По умолчанию локально используется SQLite, в Docker Compose — PostgreSQL.

## Рекомендации

- Похожие треки находятся поиском соседей в FAISS с метрикой `cosine` или `euclidean`.
- Нормализация `standard`, `minmax` или `robust` применяется перед индексированием, после неё применяются веса групп признаков.
- Co-like boost использует совместные лайки: треки, которые лайкали вместе с исходным, получают дополнительный вес.
- Персональный профиль формируется по последним лайкам пользователя. При отсутствии лайков применяется стратегия `popular`.
- `hidden_sources` исключает выбранные источники из пользовательской выдачи и поиска, сохраняя их доступными для обучения/оценки.

Подробности алгоритмов и параметры по умолчанию описаны в корневом [README](../README.md).

## Основные точки входа

| Назначение | Путь |
|---|---|
| HTTP API и маршруты | `src/recommender/interfaces/online/` |
| Предметная логика рекомендаций | `src/recommender/domain/`, `src/recommender/application/` |
| FAISS, БД, аудио и артефакты | `src/recommender/infrastructure/` |
| Online запуск | `services/online/main.py` |
| Batch-команды | `services/batch/main.py` |
| Плановые DAG | `airflow/dags/recommender.py` |
